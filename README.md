# 🚀 Scalable Projects - Full Stack Web Application

A scalable full-stack web application built using **React.js** for the frontend and **Spring Boot** for the backend. This project demonstrates modern web development practices with a clean separation between client-side and server-side components.

## 📂 Project Structure

```text
scalable-projects/
│
├── react-frontend/
│   ├── public/
│   ├── src/
│   ├── package.json
│   └── package-lock.json
│
├── springboot-backend/
│   ├── .mvn/wrapper/
│   ├── src/
│   ├── pom.xml
│   ├── mvnw
│   └── mvnw.cmd
│
└── README.md
```

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/Dineshkumar7217/scalable-projects.git
```

---

## Frontend Setup

```bash
cd react-frontend
npm install
npm start
```

Application runs on:

```text
http://localhost:3000
```

---

## Backend Setup

```bash
cd springboot-backend
mvn spring-boot:run
```

Application runs on:

```text
http://localhost:8080
```
